\# seed



Multipurpose Discord bot that saves your server's layout so you can grow it back if it gets nuked.



`/backup` saves the seed: categories, channels, roles and permissions, to a JSON file on your own PC.

`/seed` plants it: rebuilds that layout in a fresh server.



Your backups stay on your machine, nothing gets sent anywhere else.



\## Status

Early. `/backup` is first.



\## Setup

1\. `pip install -r requirements.txt`

2\. Copy `.env.example` to `.env` and put your bot token in it
